# Soulmates Client Playtest - 2026-09-30

## Environment

- Terraria 1.4.4.9 / tModLoader 2026.7.3.0 on Windows.
- Local Soulmates 0.12.1, followed by the 0.12.2 input/initiative hotfix.
- New Journey character `sqa` and new medium Journey world `Red Dab of Annoyance`. A second new Journey character `sqb` checked starter-kit initialization independently.
- Existing player characters and worlds were not used for testing.
- Screenshots are actual client captures. No gameplay scene was generated or composited.

## Observed In the Client

- Starter kit granted one Soulcore and three Blank Sigils to each fresh test character.
- Creator displayed an animated preview and changed the starting talent without activating Randomize. An AETHER Sigil was created and summoned as a visible Soulkin.
- Companion Soulwheel opened. Its Pack action opened Talk Mode correctly while a Sigil was held, without summoning another companion after the input fix.
- Manual storage moved 99 of 100 rope into the pack, leaving one with the player. Withdrawal returned the 99 and left the pack empty. Local transaction events matched both transfers.
- An initiative question did not replace open Talk Mode. It appeared after Talk Mode closed.
- Selecting the actual Always node enabled repeated tree shaking. Wood and fruit drops were visible; unsuccessful shakes eventually triggered a rest cooldown.
- Player self-right-click opened the separate emote wheel away from the Guide's hitbox. A feelings category unfolded and a native heart appeared over both player and companion.
- Companion combat produced attacks and damage; healing restored five life during encounters. Experience and level growth were visible and recorded.
- Carried rope prompted a Rope Coil crafting suggestion.
- The first test character/world was saved through the normal game menu.

## Defects and Fixes

- Inventory right-click consumed the supposedly reusable Soulcore in 0.12.1. The 0.12.2 `ConsumeItem` policy now rejects consumption and passed the actual engine hook test. Its final graphical inventory-right-click retest remains incomplete.
- Click-through from Soulmates UI could use the held Sigil. Input ownership now blocks item/tile controls through release; the Pack action was successfully retested in the client.
- Initiative prompts could replace other interfaces or move their answer targets. New prompts defer, answer nodes stay still, and the timeout is now one minute. The deferred Talk Mode case was retested.
- Companion speech overlapped the Guide dialogue. The final guard hides speech during NPC conversations and inventory views; engine visibility tests passed, but the final graphical retest remains incomplete.
- Two initial initiative clicks hit No because the tester misidentified node positions. These were input mistakes, not a proven response-mapping defect. Always is the lower-left node in the current crescent.

## Automated Verification

- Static/math harness: 2,013 assertions passed, covering 520 bilingual keys and 286 source references, layout wrapping, UI transforms, and description limits.
- Isolated tModLoader probe: 2,669 assertions passed with zero failures. Includes actual `StoreLooseItem` calls, mixed types, exact world/pack conservation, per-type limits, reservations, full packs, excluded items, independent clones, persistence, network serialization, translations, mining traversal, input ownership, and speech visibility.
- MSBuild compilation: no compiler warnings or errors. The final Workshop package was compiled natively without `-eac`: zero errors and one CS8632 nullable-annotation warning. The 2,669 engine checks were rerun successfully against that exact package. The unresolved packager image-format diagnostic remains; the mod package loads successfully.

## Not Verified By This Pass

Live multiplayer, dedicated-server gameplay, Hardmode and all ore tiers, every visual muse, acorn planting, all direct-order/mining approaches in the graphical world, final mailbox typing, and long-session stability.
