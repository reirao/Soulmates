# Soulmates 0.20.0 - Shared Instincts

**Beta candidate for tModLoader 1.4.4.** Core features are frozen while we focus
on defects, balance, clarity and compatibility. Existing Sigils remain supported;
all multiplayer participants must use 0.20.0.

## Clearer Shared Behavior

- Six autonomous abilities share one registry for saved Ask/Always/Never
  permissions, native symbols, rule buttons and energy/mood requirements.
- A per-companion activity controller prioritizes defense, pause and retained
  assignments. Lower-priority movement no longer replaces a completed task's
  final frame. Active critter visits and defense have matching status text.
- Offers, pending questions and answers share the same consent checks. Recovery,
  changed routines and Never reject stale answers; independent client mutations
  and unknown/UI-only quick actions are rejected.
- Preserve previous cargo-transfer, native tool/use, save identity, input and
  expression repairs. Existing saves and the 0.19.9 binary field order remain
  compatible; all peers still need the current version.

## Where To Find Things

- Companion > **Games** > Rock, paper, scissors: independent choices and native
  symbols. Bond keeps gestures; no extra games or XP rewards are added.
- Companion > **Critters**: Watch, Company, Pet Collect, Off. Ordinary catching
  uses a built-in basic net capability, not a free withdrawable item. Lava critters
  need a carried lava-proof upgrade. Protected creatures and cargo limits apply.
- Commands > **Initiative Rules**: independent Company and Collect rules, alongside
  gathering, mining, forestry and treasure. Yes allows one target; Always is saved
  for that ability; direct orders do not authorize future automatic visits.
- Work > **Mining Mode / Automatic mining**: individual ore/material permissions.
  Terrain needs opt-in; plant/decor support protection and native tool rules stay.
- Commands > **Pause / Resume / Abort**; Details or `V` for full Talk Mode;
  player wheel > Emotes for the 151 native symbols and item subcategories.

Company guides existing real critters, not copies. Greetings can wait behind
speech/questions, and tree context remains available during shake cooldowns.
Dry-branch pruning remains limited to supported vanilla frames and needs an axe.
Equipment, level-scaled Resources and the uncapped Wallet remain separate.

## Evidence And Honest Limits

The creator reports an initial playtest broadly working and Workshop publication
on October 5. Steam shows the 11:46 CEST upload with moderator approval pending
at this documentation update. The normal local installation was header/hash-verified.
This does not certify every graphical control, critter reaction, progression,
60-minute session or connected multiplayer scenario. Those gates remain open in
[BETA.md](https://github.com/reirao/Soulmates/blob/main/BETA.md).

The exact attached package passed **43,741 native-engine assertions**, **156
separate safety expectations** and **50,511 static/controller/localization
assertions**. Production compilers report zero warnings/errors; the general
test-only probe retains 34 known compatibility warnings. Nine catalogs contain
853 keys. Automated fixtures are not a rendered or connected multiplayer playtest.
See [verification](https://github.com/reirao/Soulmates/blob/main/tests/BETA-STABILIZATION-0.20.0-2026-10-05.md)
and [the German checklist](https://github.com/reirao/Soulmates/blob/main/tests/PLAYTEST-CHECKLIST-0.20.0-DE.md).

Some mixed-language multiplayer replies retain the server's language. New
translations need native-speaker review. The current genuine screenshot gallery
is from October 1, not newly captured 0.20.0 footage. New pet slots, more minigames,
combat critter swarms and procedural artwork are not promised by this release.
