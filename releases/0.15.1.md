# Soulmates 0.15.1 - Careful Company

AETHER-EGG Alpha maintenance patch for the existing Soulmates companions. Update every multiplayer participant to the same version before joining.

## Fixes

- Native text entry and existing Soulmates menus retain input ownership. Wheel shortcuts and automatic initiative choices wait instead of replacing the current interface.
- An answered multiplayer initiative waits for acknowledgement instead of immediately reopening on stale synchronized state. A ten-second timeout allows another attempt if no acknowledgement arrives.
- Gathering distinguishes nearby drops that cannot fit from an empty area. The pickup transaction itself also rejects multiplayer-client mutation.
- Companion healing sends a real health delta to the owning client. Carried mana potions send bounded mana recovery, and potion sickness, mana sickness, and food buffs reach that client explicitly.
- Invulnerable enemies no longer monopolize defense. Existing attack strength is unchanged.
- The active Sigil must remain carried. Moving it to a chest, bank, or the world recalls the companion; holding it on the cursor while rearranging single-player inventory preserves its binding.
- Server commands also revalidate the binding and a living owner before changing cargo, progression, or behavior, including requests queued just before a Sigil move.
- Perk-unlock experience is persisted immediately. A full NPC pool returns a clear summon failure instead of indexing the sentinel slot or reporting success.
- Mailbox notes retain up to 360 characters end to end. Future automatic Field Notes omit exact coordinates, names, and chat; manually typed notes retain their contents. Existing feedback files are not rewritten or uploaded.
- Feedback reuses its cargo-count buffers and caches the opt-in marker instead of allocating containers and checking the filesystem every frame.
- Omit the optional mini-icon from packaging to avoid a verified tModLoader stream-position bug. The full mod/Workshop icons and gameplay graphics remain unchanged.

## Scope

This is a maintenance patch, not another feature expansion. Existing Sigils, resident relationships, native emotes, forestry, carried insects, the three cargo compartments, resource level limits, and the uncapped wallet remain compatible.

The [revision report](../tests/REVISION-2026-10-01.md) distinguishes isolated engine assertions from actual playtesting. No fresh graphical client session, screenshots, complete progression test, or live multiplayer pass is claimed for this patch. All multiplayer participants must use the same version when it is installed.
