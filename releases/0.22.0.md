# Soulmates 0.22.0 - Character and Company

Local beta candidate, not published. Client installation is recorded separately.

## Repairs

Company/Collect previously used a separate automatic scheduler. Reproduction against 0.21.0 showed concurrent gathering could starve visits, and a personal question blocked already approved Always visits. Both now use shared attention. Ask still requires a reply, Never prevents automatic work, and personal questions remain answerable. New resident visits cannot steal active critter work. Reused NPC slots cannot inherit visits from a replaced object.

## Character window

Details or `V`: book/toolbox/wrench select Conversation, Equipment and Diagnostics. Portrait/vitals sit beside native tool/trinket displays, real pet choices and cargo. A full-width scrollable reply strip stays separate. Pause/Resume/Abort use actual existing actions. Tool slots display carried capabilities; this is not a generic armor/weapon equip system.

Only Zephyr Fish and Nectar support her own item-backed pet, with native animated art and harmless custom following. Your own pet/buffs stay untouched; real items remain in cargo. Switching, dismissal, last-item withdrawal and recall retire followers. Company uses supported natural critters with native collision, health and despawning, not a combat swarm or noclip/pathfinding for all animals.

## Diagnostics

The wrench view is read-only: task, stamina, permissions, questions, critter gates/candidates, owned pets and bounded recent transitions. Explicit export writes `SoulmatesFeedback/diagnostic-latest.txt` under the active save folder. No automatic saving, uploads or Field Notes activation. Names, chat and exact world coordinates are omitted. MP labels client state, not server history. Technical details remain English; view labels exist in nine languages.
