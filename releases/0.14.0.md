# Soulmates 0.14.0 - Attentive Souls

Prepared local AETHER-EGG Alpha build. No new GitHub or Workshop release has been published for this version.

## Controls

- Right-click the companion: her commands, work, bonding, pack, details, and mailbox.
- Right-click your own player: Emotes, Point tools, and Mailbox. G opens Emotes directly.
- Right-click clear air: Point wheel (Look / Gather / Mine / Forest). Further right-clicks cycle to Area work and back.
- Choose a Point tool, then left-click nearby targets repeatedly. Right-click opens the Area wheel; Escape cancels targeting. The wheel's native X or an outside click returns to normal controls.
- Tiles, other NPCs, inventory actions, and active held-item alternate actions retain priority when starting a wheel.
- Commands > Initiative Rules: cycle Ask, Always, or Never separately for gathering, mining, forestry, and treasure. Reset all remains available.

## Behavior

Nearby opportunities are weighted by distance, talent, recent observed habits, and waiting time. Independent cooldowns prevent one task or unanswered prompt from delaying every other kind. Imitation remains bounded game logic, not a general-purpose learning model.

Look is read-only. Directed forestry resolves a real tree anchor, fallen log, or safe grass planting spot; it performs one task using existing restrictions and carried acorns. It does not chop living trunks. Gather and Mine preserve their existing cargo and protected-tile rules.

Pending questions expire during combat and reject changed targets, insufficient capacity, low mood/energy, or disabled autonomy. Directed world-item requests validate type/prefix on the server and track item identity during travel. All multiplayer participants must use 0.14.0.
