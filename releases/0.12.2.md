# Soulmates 0.12.2 - Patient Choices

The current AETHER-EGG Alpha, bringing the public source and package up to the tested 0.12.2 build. Older experimental 9.9.x releases remain available as history, not the current version line.

## Changes Since Workshop 0.12.0

- Preserve the reusable Soulcore when it is right-clicked in the inventory.
- Give Soulmates interfaces ownership of item and tile input, including the closing click until the mouse is released.
- Defer new initiative questions while another menu or NPC conversation is open. Keep answer nodes stationary and allow one minute to respond.
- Keep companion speech out of vanilla NPC conversations and inventory views.
- Resolve English and German mining replies, quick actions, mailbox labels, and old memory keys as readable text.
- Anchor named speech to the companion with zoom-aware placement, cached wrapping, longer readability, and a restrained fading trail.
- Improve Talk Mode layout, numerical status, cargo hitboxes, resizing, preview bounds, small-screen wheel sizing, and multiplayer request recovery.
- Revalidate changed mining terrain, enforce travel timeouts, refresh stale ore choices, and report blocked or completed plans accurately.

The four mining approaches, contextual ore wheel, local feedback mailbox, learning, native emotes, forestry, and persistent Sigils remain available.

## Verification

- Production build: 0 compiler warnings and errors.
- Static/math checks: 2,013 assertions passed.
- Isolated tModLoader checks: 2,669 assertions passed, 0 failures. These include actual engine pickup transactions, mixed cargo, conservation, item reserves, full packs, owner reservations, persistence, localization, input capture, and speech visibility.
- Actual single-player playtest with a new Journey character and world: starter kit, creation, animated companion, pack storage/withdrawal, native emote wheels, repeated tree shaking, combat, healing, and saved progress.

This is not a complete multiplayer, Hardmode, all-muse, acorn-planting, or long-session certification. The Soulcore consumption policy and final NPC-dialogue speech guard passed engine checks; their final graphical retests were not completed. The packager still reports `Image loading failed: unknown image type`, although the package builds and loads.

## Upgrade and Feedback

Existing Soulbound Sigils remain compatible. If a manually installed 9.9.x `.tmod` overrides the Workshop package, remove that duplicate and restart tModLoader. A normal Workshop subscription updates its own package.

Please report the version, what happened, and whether you played single-player or multiplayer. The creator has limited progression time; practical reports and small happy moments are both welcome. The optional in-game AETHER Mailbox writes local feedback and bug context only. Nothing is uploaded automatically.
