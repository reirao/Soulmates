# Soulmates 0.25.0 - A Place to Belong

Local beta candidate for tModLoader 1.4.4, October 11, 2026. This pass prepares
candidate docs; it does not install a package, publish a GitHub release or update
Workshop. Existing Sigils retain identity, learning, permissions, cargo and pets.
All peers testing this candidate need 0.25.0; mixed-version multiplayer is unsupported.

## A Place to Belong

- Bounded place memory belongs to one Sigil and is scoped to the world's identity.
  Enclosed rooms with manufactured walls, floor and furniture provide shelter
  evidence. The owner's selected spawn needs an actual valid bed; assigned
  resident housing uses a home anchor in the sampled room.
- Separated returns can make a shelter familiar. Standing still does not add
  repeated visits, and familiarity never establishes ownership of a build.
  Assigned resident housing is not offered for claiming.
- The existing answer wheel offers our home (SharedHome), her little home
  (CompanionHome), just a stop (NotHome), or Later. Only the player's answer
  assigns a home role; Later leaves it unchanged. Answers recheck the captured
  world and room. Changed shelter is sampled again.
- Recognized home chests are excluded from automatic treasure rediscovery.
  Explicit treasure search still works. Shelter recognition does not construct,
  copy or remodel houses.

## Optional EVIL

EVIL is off by default and saved per Sigil. Toggle it in her Commands wheel or
with the fourth task button in Details, marked with a laughing face. Safe idle
banter and celebrations of actual completed work give small successes a
theatrical villainous tone. Rock, paper, scissors quips follow the existing fair
result. Celebrations wait behind threats, work, questions and critter reactions.

This changes presentation only. Consent, task selection, rewards, cargo, damage,
terrain and empathy for hurt critters remain intact. It is not an extra ability,
automatic permission or a different task executor.

## Focused Repairs

- Native-first input protects inventory, typing, NPC dialogue, cursor-held items
  and alternate item actions. Stale captured targets, pending answers and changed
  companion/Sigil identities cannot silently redirect an old command.
- Answer-wheel nodes fade at fixed positions, matching the clickable targets
  throughout opening.
- Recovery accounts for low mood and energy. Work rechecks current targets and
  bounded timeouts; real threats take priority over training dummies.
- Critter visits and queued reactions validate live targets. Watch, Company and
  Collect retain consent, recovery, visibility, native-net and protected-species
  rules. Catching remains separate from death.
- Companion familiars validate binding and selection before drawing. Twelve
  real-item pet slots remain separate from the player's pet; native artwork uses
  custom movement, not copied player-pet AI or arbitrary modded drawing.
- All nine Terraria language catalogs contain 991 complete keys. AI-authored
  translations still need native-speaker feedback; some multiplayer replies
  retain the server language.

## Privacy and Disclosure

Optional Mailbox/Field Notes start off and stay local. Nothing uploads or
automatically reaches the developer. Automatic notes omit account, character
and world names, chat and coordinates; place coordinates stay in the local game
save. Typed notes retain the text entered. Share only the notes you choose.

Development uses extensive AI assistance in code, writing, UI and visual work.
Workshop/mod icons and original Soulkin art are AI-generated; other creature,
item, inventory and emote graphics reuse Terraria assets. No online AI service
runs in the mod. These notes describe implemented scope without future feature
promises or autonomous building.
