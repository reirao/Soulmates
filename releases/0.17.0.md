# Soulmates 0.17.0 - Deliberate Mouse Modes

Local candidate, not installed or publicly published by this revision.

Terraria is the normal mouse mode again. Open your character or companion wheel and deliberately choose Me or Soulmate. Me can point out what the cursor sees and open native player emotes. Soulmate offers suitable nearby tasks for the original clicked target, including collection, inspection, mining and forestry. The full companion tools remain available.

Native symbols select each mode; a small cursor symbol indicates an active non-native mode. Right-click inside an open wheel cycles Me, Soulmate, then Terraria. X or Escape returns to native use. Inventory, text entry, NPC dialogue and items held on the cursor keep their normal priority. Mode selection itself does not approve ongoing autonomous terrain changes.

Targets are captured before entering the menu and checked again before executing. Changed targets are rejected rather than silently retargeted. Existing server-authoritative orders and native emote routing remain in use. Existing Sigils need no migration.

Verification results and remaining graphical/live multiplayer checks are recorded in `tests/INPUT-MODES-2026-10-02.md`.
