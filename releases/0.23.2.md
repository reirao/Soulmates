# Soulmates 0.23.2 - Clear Pet Actions

Beta candidate, October 9, 2026. The creator reports a positive playtest and requests publication. This release includes the intervening 0.23.0 and 0.23.1 refinements below; older development entries are not republished into the Workshop log.

## Included Since 0.22.2

- Work restores Find nearby ore and Mine area directly beside Config/Last.
- Twelve dedicated pet-inventory slots hold real eligible reusable summon items, discovered from native item/buff/projectile metadata instead of a fixed two-item list.
- Pets opens directly from her wheel and character panel. Give items from a paged view of your inventory; favorites and stale/conflicting transfers are protected.
- One harmless item-backed familiar can accompany her alongside your own pet. Native frames and basic light are supported; original player-pet AI, special utilities and arbitrary mod drawing are not cloned.
- Existing Sigils retain compatible cargo and selected pets. All multiplayer peers must use 0.23.2 because pet inventory extends the synchronized profile.

## Corrected Claims

The player reports V does not work in the real 0.23.1 client. Earlier checks injected the registered trigger directly and were incorrectly presented as proof of keyboard operation. That error remains visible as [the V key lesson](https://github.com/reirao/Soulmates#the-v-key-lesson), not a claim that V is fixed. Current instructions use her wheel's Details/Pets entries. The Sigil displays the actual keyboard assignment or an unassigned state; diagnostics include the assignment and input gates. This patch does not force V or overwrite custom/unbound controls.

## Pets

An owned item is not the same as a summoned familiar. Left-click an owned pet to summon; right-click returns its real item. Giving the first item to an empty pet inventory selects it automatically. Additional gifts neither replace a selected pet nor override an explicit dismissal. The manager shows no summon, waiting or the actual active familiar. Withdrawing the last supporting item removes the familiar immediately. Existing selections and cargo remain compatible.

Pet selection enters optional local field notes, without names or exact positions. Runtime checks include the reported Eucalyptus Sap alongside the previous pet families, ordinary updates, switching and lifecycle cleanup. These are not screenshots or proof of rendered visibility. Native sprites use harmless custom floating movement, not original player-pet AI or special utilities.
