# Soulmates: Classic Showcase, October 5

20 genuine, unaltered captures from a live **0.22.0** Classic playtest on October 5, 2026. No generated screenshots, retouching, resizing or extra cropping. They precede the 0.22.1 repairs; they are not evidence that every displayed action completed. [Provenance and SHA256 hashes](provenance.json) preserve capture times and dimensions. Images are excluded from the `.tmod`.

The [playtest record](../../../tests/LIVE-SHOWCASE-0.22.0-2026-10-05.md) distinguishes observed success, failures and untested behavior. In particular, these views exposed inactive cargo controls and fading unanswered questions, repaired afterward. Company/capture/loss and owned-pet summoning were not completed visually. The tunnel image shows configuration, not a finished tunnel.
